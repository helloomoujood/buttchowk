# Buttchowk Restaurant & Cafe (Next.js 14, App Router)
npm install
npm run dev     # http://localhost:3000
npm run build && npm start

Routes: / , /about , /menu , /catering , /contact , /book
Menu data and illustrations: components/data.js
Set NEXT_PUBLIC_SITE_URL=https://yourdomain.ca for sitemap.xml and robots.txt.
Forms show a confirmation only; connect them to email or a booking service (see components/client.jsx Form).
